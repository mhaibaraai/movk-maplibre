## 简介

`MaplibreMaskLayer` 以全球范围为外环、目标区域的外环为孔洞生成反向遮罩，`data` 支持 Polygon、MultiPolygon、Feature 与 FeatureCollection。`outline` 开启后额外描绘目标区域边界，数据变化时经 `setData` 增量更新。

::note
目标区域自身的孔洞（如飞地）不参与遮罩，会与区域一同保持高亮。
::
