## 简介

`MaplibreRasterLayer` 叠加外部栅格瓦片服务（`{z}/{x}/{y}` 模板 URL），支持 `tileSize` / `scheme` / `minzoom` / `maxzoom` / `attribution` / `opacity`。天地图等国内底图见 [扩展能力](/docs/extensions/tianditu)。

::tip
`url` 可替代 `tiles` 传入 TileJSON 地址或协议地址，如注册 [COG](/docs/extensions/cog) 协议后的 `cog://` 地址。
::
