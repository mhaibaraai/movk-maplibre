## 简介

`MaplibreGraticuleLayer` 只生成视口（外扩一个步长）内的经纬线，平移超出外扩范围或步长变化时才重算；线条已加密，球形投影下呈曲线。`step` 省略时按缩放级别自动选择，`labels` 在视口边缘标注度数，世界视图下改为沿地图中心标注。
