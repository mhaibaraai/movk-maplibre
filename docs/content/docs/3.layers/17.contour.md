## 简介

`MaplibreContourLayer` 基于 [maplibre-contour](https://github.com/onthegomap/maplibre-contour)，在 worker 中把 `raster-dem` 瓦片实时转为矢量等高线：`thresholds` 按缩放级别设定次线与主线间距，主线沿线标注高程。`demUrl` 可与 `MaplibreTerrain` 共用同一套 DEM。

::note
需额外安装可选依赖 `maplibre-contour`。组件内部由 `MaplibreLayer` 组成，放入 `MaplibreLayerGroup` 即可随组控制显隐与透明度。
::

## 用法

在珠峰一带叠加等高线：

::component-example
---
name: ContourLayerExample
prettier: true
options:
  - name: lineColor
    label: color
    default: '#fde68a'
    items:
      - '#fde68a'
      - '#f43f5e'
      - '#ffffff'
  - name: labels
    label: labels
    default: true
    items:
      - true
      - false
---
::

::tip
`multiplier` 设为 `3.28084` 并把 `unit` 设为 `'ft'` 即可按英尺显示；`thresholds` 与 `multiplier` 变化时仅更新瓦片地址，不重建图层。
::
