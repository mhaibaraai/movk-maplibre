## 简介

`MaplibrePopup` 在指定 `lnglat` 锚定一个弹窗，默认插槽渲染任意内容；`lnglat` 变更时响应式更新位置，关闭时触发 `close` 事件。

## 用法

默认插槽渲染弹窗内容，`options.closeOnClick` 等选项透传给 maplibre：

::note
`MaplibreTooltip` 内部只有一个 Popup 实例，无法同时展开多个要素的弹窗；它的 `feature` 来自鼠标事件，组件并不持有要素列表。要让图层要素的弹窗同时常驻，请直接用构造 GeoJSON 的源数组 `v-for` 出多个 `MaplibrePopup`。若点位是 DOM 标记，用 [`MaplibreMarker`](/docs/core/marker) 的 `:open="true"` 更直接。
::

### 长内容与默认样式

弹窗统一使用 `movk-popup` 类，提供圆角、边框、阴影、自动换行与细滚动条。关闭按钮保留 MapLibre 原生行为，点击区域为 28px、关闭符号为 20px，并提供悬停、按下和键盘焦点样式；没有关闭按钮时不预留关闭区域。该外观同样适用于 Marker 的 `#popup` 插槽和 `MaplibreTooltip`，不依赖 Nuxt UI。

滚动条只修饰已有滚动区域，不限制内容高度。长列表需在插槽内自行设置 `max-height` 和 `overflow-y: auto`；以下示例还可以检查长标题、关闭按钮、深浅外观及不同箭头方向：

### 自定义外观

`options.className` 会与 `movk-popup` 一起保留。可在全局样式中针对自定义类覆盖以下 CSS 变量；默认兼容宿主 Nuxt UI 的主题变量，没有主题变量时采用独立的浅色或 `.dark` 深色回退值。

| CSS 变量 | 用途 |
| --- | --- |
| `--movk-popup-bg` | 内容与箭头背景 |
| `--movk-popup-color` | 正文颜色 |
| `--movk-popup-muted` | 关闭按钮颜色 |
| `--movk-popup-border` | 边框颜色 |
| `--movk-popup-radius` | 内容圆角 |
| `--movk-popup-shadow` | 弹窗阴影 |
| `--movk-popup-focus` | 关闭按钮焦点颜色 |
| `--movk-popup-scrollbar` | 滚动条滑块颜色 |
| `--movk-popup-scrollbar-hover` | 滚动条悬停颜色 |
| `--movk-popup-font-family` | 弹窗字体 |

```vue
<MaplibrePopup :lnglat="[116.397, 39.908]" :options="{ className: 'site-popup' }">
  自定义弹窗内容
</MaplibrePopup>
```

```css
.site-popup {
  --movk-popup-radius: 12px;
  --movk-popup-focus: #2563eb;
}
```

::note
弹窗实际挂载在地图 DOM 内。继承变量应设置在地图容器、它的祖先或全局自定义类上；仅在插槽原先的 Vue 祖先上设置变量可能无法继承。组件内的 scoped 样式需要使用全局选择器或通过地图容器传递变量。
::
