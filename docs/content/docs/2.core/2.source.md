## 简介

`MaplibreSource` 声明式管理一个 maplibre-gl 数据源：地图就绪时 `addSource`，`source` 变更时按类型走增量更新（geojson 调 `setData`、vector 调 `setTiles`）而非整源重建，卸载时安全移除。子图层经 `source="<sourceId>"` 字符串引用该源，或直接嵌套在其中省略 `source`。

::tip{to="/docs/core/layer"}
同一份数据可同时供多个图层消费，这是显式 `MaplibreSource` 相较 MaplibreLayer 内联源的价值。
::

### 嵌套关联

`sourceId` 可省略，按类型自动生成（如 `geojson#1`）。嵌套在 `MaplibreSource` 内的图层省略 `source` 即引用该源，嵌套在图层内的 `MaplibreTooltip` 省略 `layerId` 即绑定该图层，全程无需手写 id：

::note
在 setup 中按 id 调用 API（如 `useFeatureState(layerId)`、`map.getLayer()`）或用字符串 `beforeId` 锚定时，仍需显式传 id。自动 id 形如 `<类型>#<序号>`（如 `fill#1`），为保留格式，与手写 id 互不冲突；手写 id 请勿使用该形式，否则开发期会告警。
::
