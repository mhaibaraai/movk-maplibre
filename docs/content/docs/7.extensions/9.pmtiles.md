## 简介

[PMTiles](https://docs.protomaps.com/pmtiles/) 把整套瓦片打包为单个文件，浏览器经 HTTP Range 按需读取，无需瓦片服务器。注册 `pmtiles://` 协议后，`MaplibreSource` 与 `MaplibreRasterLayer` 的 `url` 直接写 `pmtiles://` 地址即可。

::note
需额外安装可选依赖 `pmtiles`，并确保文件所在服务支持 Range 请求与 CORS。
::

## 注册协议

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { pmtiles: true }
  }
})
```

```ts [main.ts（Vue + Vite）]
import { registerPmtilesProtocol } from '@movk/maplibre/utils/pmtiles'

// 在首个地图创建前同步注册；重复调用只注册一次
registerPmtilesProtocol()
```
::

`registerPmtilesProtocol` 返回 `Protocol` 实例，可用 `protocol.add(new PMTiles(source))` 登记自定义来源（如本地文件）。
