## 简介

ZZTS 二维动态切片服务按 GeoSOT 网格出图：先由 `media` 接口返回图层范围，再由 `media/elements` 接口按视口返回若干张带经纬度范围（WGS84）的网格图片。`zzts://` 协议在浏览器端把这些网格图片拼合、重投影为 512 像素的 Web 墨卡托瓦片，渲染完全交给 MapLibre 原生栅格管线：瓦片缓存、父瓦片兜底与淡入、移出视口时中止请求均自动生效。

注册后，`MaplibreRasterLayer` 的 `url` 写成 `zzts://` + `media` 接口地址（含 `layerName`、`dictCode` 等查询参数）即可。

::note
`tileSize` 须设为 `512`，与协议输出及比例尺换算一致。`minzoom` / `maxzoom` 缺省由图层元数据推算，可在 `MaplibreRasterLayer` 上覆盖。
::

## 注册协议

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { zzts: true }
  }
})
```

```ts [main.ts（Vue + Vite）]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

registerZztsProtocol()
```
::

## 用法

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12 }">
    <MaplibreRasterLayer
      url="zzts://https://example.com/sstde_v4/v1/zzts/layer/media?layerName=xxx-01&dictCode=xxx"
      :tile-size="512"
      :opacity="0.8"
    />
  </MaplibreMap>
</template>
```

::tip
地址上的查询参数会原样带给 `media` 与 `elements` 接口，`layerId`、`token` 等服务参数直接追加在地址后即可。
::

::note
服务端尚未生成的网格图（`png_status` 为 0 或请求返回 404）会自动以更粗一级（最多 3 级）的网格图垫底补洞，404 结果会被缓存，不会重复请求。
::

## 自定义请求

接口需要鉴权头或改走代理时，不开启模块选项，改为在客户端插件中自行注册并传入 `fetch`；元数据、元素列表与元素图片共用该函数：

```ts [plugins/zzts.client.ts]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

export default defineNuxtPlugin(() => {
  registerZztsProtocol({
    fetch: (input, init) => fetch(input, { ...init, headers: { sessionId: useCookie('sessionId').value ?? '' } }),
    cacheSize: 512
  })
})
```

| 选项 | 说明 |
|------|------|
| `fetch` | 自定义请求函数，缺省为全局 `fetch` |
| `cacheSize` | 元素图片缓存数量，缺省 `256`；相邻瓦片共用同一网格图片时不重复下载 |
