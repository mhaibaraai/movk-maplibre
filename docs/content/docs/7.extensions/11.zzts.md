## 简介

ZZTS 二维动态切片服务按 GeoSOT 网格出图：`media` 接口返回图层范围，`media/elements` 接口按范围返回若干张带经纬度范围（WGS84）的网格图片。`zzts://` 协议在浏览器端把这些网格图片拼合、重投影为 512 像素的 Web 墨卡托瓦片，渲染交给 MapLibre 原生栅格管线：瓦片缓存、父瓦片兜底与淡入、移出视口时中止请求均自动生效，globe 投影与地形贴合同样可用。

`MaplibreZztsLayer` 在协议之上提供多边形裁剪、定位、高分屏出图与色彩调整，并在挂载时自动注册协议。

::note
相邻 2×2 个瓦片合并为一次元素列表请求，请求范围裁到图层范围内；加载失败（如服务端尚未生成而返回 404）的网格图以更粗一级（最多 3 级）垫底补洞，404 结果会被缓存；网络错误与 5xx 按退避自动重试。
::

## 用法

`url` 填 `media` 接口地址（含 `layerName`、`dictCode` 等查询参数），查询参数会原样带给 `media` 与 `elements` 接口：

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12 }">
    <MaplibreZztsLayer
      url="https://example.com/sstde_v4/v1/zzts/layer/media?layerName=xxx-01&dictCode=xxx"
      :opacity="0.8"
      auto-fit
    />
  </MaplibreMap>
</template>
```

::tip
不使用组件时，`MaplibreRasterLayer` 的 `url` 写成 `zzts://` + `media` 地址、`tile-size` 设为 `512` 即可；高分屏参数可写在地址 hash 上，如 `zzts://<media 地址>#pixelRatio=2`。
::

## 示例

### 裁剪与定位

`clip` 仅保留区域内的影像像素，区域外露出下层底图，孔洞（飞地）同样挖空；`auto-fit` 在元数据加载后定位到图层范围，也可经组件实例调用 `fit()`：

```vue
<script setup lang="ts">
import type { Polygon } from 'geojson'

const district: Polygon = { type: 'Polygon', coordinates: [[[121.5, 29.9], [121.7, 29.9], [121.7, 30.05], [121.5, 30.05], [121.5, 29.9]]] }
const imagery = useTemplateRef('imagery')
</script>

<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 11 }">
    <MaplibreZztsLayer ref="imagery" :url="mediaUrl" :clip="district" :fit-options="{ padding: 40 }" />
  </MaplibreMap>
  <UButton label="定位" @click="imagery?.fit()" />
</template>
```

### 3D 场景

请求范围裁到图层范围后，任意缩放级别都能出图：globe 缩小到地球视角、大俯仰角下的远景均可见；叠加地形时影像由 MapLibre 原生贴合。高分屏下设 `pixel-ratio` 取更细一级网格：

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12, pitch: 70, maxPitch: 85 }">
    <MaplibreProjection type="globe" />
    <MaplibreTerrain :source="demSource" :exaggeration="1.5" />
    <MaplibreZztsLayer :url="mediaUrl" :pixel-ratio="2" />
  </MaplibreMap>
</template>
```

## 注册协议

`MaplibreZztsLayer` 会按缺省配置自动注册协议。直接使用 `MaplibreRasterLayer` 时需提前注册：

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { zzts: true }
  }
})
```

```ts [main.ts（Vue + Vite）]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

registerZztsProtocol()
```
::

### 自定义请求

接口需要鉴权头或改走代理时，在客户端插件中自行注册并传入 `fetch`，元数据、元素列表与元素图片共用该函数。不同服务需要不同配置时，以不同 `scheme` 分别注册，再在组件上指定 `scheme`：

```ts [plugins/zzts.client.ts]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

export default defineNuxtPlugin(() => {
  registerZztsProtocol({
    scheme: 'zzts-auth',
    fetch: (input, init) => fetch(input, { ...init, headers: { sessionId: useCookie('sessionId').value ?? '' } })
  })
})
```

| 选项 | 说明 |
|------|------|
| `scheme` | 协议名，缺省 `'zzts'`；同名重复注册时新选项被忽略并告警 |
| `fetch` | 自定义请求函数，缺省为全局 `fetch` |
| `cacheSize` | 元素图片缓存数量（压缩数据），缺省 `256` |
| `retry` | 网络错误或 5xx 的重试次数，缺省 `2`；404 不重试 |
| `metatileSize` | 合并请求边长（瓦片数，取 2 的幂），缺省 `2`；设为 `1` 关闭合并 |
