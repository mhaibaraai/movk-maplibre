## 简介

`useLayerTree` 返回地图中所有带 `title` 的 [`MaplibreLayerGroup`](/docs/core/layer-group)，按 `zIndex` 降序排列（上层在前，同值保持声明顺序）。每项的 `setVisible`、`setOpacity`、`setZIndex` 写回对应组的 `v-model`，因此自绘面板与 [MaplibreLayerControl](/docs/controls/layer-control)、[MaplibreLegend](/docs/controls/legend) 始终同步。适合把图层面板放在应用侧栏、使用 Nuxt UI 等组件库搭建界面的场景。

::note
在 `<MaplibreMap>` 子树外使用时，通过 `options.mapId` 指定目标地图，并为该地图设置 `map-id`。
::

## API

### `useLayerTree()`{lang="ts-type"}

::field-group
  ::field{name="options.mapId" type="string"}
  目标地图 id；在 `<MaplibreMap>` 子树外使用时必填。
  ::
::

返回 `ComputedRef<LayerTreeItem[]>`，每项包含：

::field-group
  ::field{name="id" type="string"}
  组的唯一标识。
  ::
  ::field{name="title" type="string"}
  组标题。
  ::
  ::field{name="visible" type="boolean"}
  组自身的显隐开关。
  ::
  ::field{name="opacity" type="number"}
  组自身的透明度，范围 0..1。
  ::
  ::field{name="zIndex" type="number"}
  组自身的层级，越大越靠上。
  ::
  ::field{name="legend" type="LegendItem[]"}
  图例项，`legend` prop 优先，否则由子图层颜色推导。
  ::
  ::field{name="setVisible" type="(visible: boolean) => void"}
  写回组的 `v-model:visible`。
  ::
  ::field{name="setOpacity" type="(opacity: number) => void"}
  写回组的 `v-model:opacity`，超出 0..1 的值会被钳制。
  ::
  ::field{name="setZIndex" type="(zIndex: number) => void"}
  写回组的 `v-model:z-index`，图层与列表随之重排，可用于自绘排序面板。
  ::
::
