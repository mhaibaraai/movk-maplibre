## Introduction

`useLayerTree` returns every [`MaplibreLayerGroup`](/docs/core/layer-group) with a `title` on the map, sorted by `zIndex` descending (top first, ties keep declaration order). Each item's `setVisible`, `setOpacity` and `setZIndex` write back to that group's `v-model`, so a custom panel stays in sync with [MaplibreLayerControl](/docs/controls/layer-control) and [MaplibreLegend](/docs/controls/legend). It suits layer panels placed in an app sidebar and built with a component library such as Nuxt UI.

::note
Outside the `<MaplibreMap>` subtree, pass the target map through `options.mapId` and set `map-id` on that map.
::

## API

### `useLayerTree()`{lang="ts-type"}

::field-group
  ::field{name="options.mapId" type="string"}
  Target map id; required outside the `<MaplibreMap>` subtree.
  ::
::

Returns `ComputedRef<LayerTreeItem[]>`, where each item contains:

::field-group
  ::field{name="id" type="string"}
  Unique id of the group.
  ::
  ::field{name="title" type="string"}
  Group title.
  ::
  ::field{name="visible" type="boolean"}
  The group's own visibility switch.
  ::
  ::field{name="opacity" type="number"}
  The group's own opacity, 0..1.
  ::
  ::field{name="zIndex" type="number"}
  The group's own stacking order; higher is on top.
  ::
  ::field{name="legend" type="LegendItem[]"}
  Legend items, from the `legend` prop or derived from child layer colors.
  ::
  ::field{name="setVisible" type="(visible: boolean) => void"}
  Writes back to the group's `v-model:visible`.
  ::
  ::field{name="setOpacity" type="(opacity: number) => void"}
  Writes back to the group's `v-model:opacity`; values outside 0..1 are clamped.
  ::
  ::field{name="setZIndex" type="(zIndex: number) => void"}
  Writes back to the group's `v-model:z-index`; layers and the list reorder accordingly, which suits a custom ordering panel.
  ::
::
