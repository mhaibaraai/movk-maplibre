## Introduction

`MaplibreRasterLayer` overlays an external raster tile service using a `{z}/{x}/{y}` template URL. Supports `tileSize`, `scheme`, `minzoom`, `maxzoom`, `attribution`, and `opacity`. For Chinese basemap services like Tianditu, see [Extensions](/docs/extensions/tianditu).

::tip
`url` can replace `tiles` with a TileJSON address or a protocol address, such as a `cog://` address after registering the [COG](/docs/extensions/cog) protocol.
::
