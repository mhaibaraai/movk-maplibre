## Introduction

A ZZTS dynamic tiling service serves imagery on a GeoSOT grid: the `media` endpoint returns the layer extent, and the `media/elements` endpoint returns the grid images (with WGS84 extents) within a given area. The `zzts://` protocol composes and reprojects those grid images into 512px Web Mercator tiles in the browser, so rendering stays on the native MapLibre raster pipeline: tile caching, parent-tile fallback with fading and aborting requests for tiles leaving the viewport all work out of the box, and so do the globe projection and terrain draping.

`MaplibreZztsLayer` builds on the protocol with polygon clipping, fit-to-bounds, HiDPI output and color adjustments, and registers the protocol automatically when mounted.

::note
Every 2×2 neighbouring tiles share one element-list request, clipped to the layer extent. Grid images that fail to load (for example a 404 because the service has not generated them yet) are filled from up to 3 coarser levels drawn underneath, and 404 results are cached. Network errors and 5xx responses are retried with backoff.
::

## Usage

Set `url` to the `media` endpoint address (including query parameters such as `layerName` and `dictCode`); the query is forwarded to both the `media` and `elements` endpoints:

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12 }">
    <MaplibreZztsLayer
      url="https://example.com/sstde_v4/v1/zzts/layer/media?layerName=xxx-01&dictCode=xxx"
      :opacity="0.8"
      auto-fit
    />
  </MaplibreMap>
</template>
```

::tip
Without the component, set the `url` of `MaplibreRasterLayer` to `zzts://` followed by the `media` address and `tile-size` to `512`. HiDPI output can be requested in the address hash, e.g. `zzts://<media address>#pixelRatio=2`.
::

## Examples

### Clipping and fitting

`clip` keeps only the imagery pixels inside the area, leaving the base map visible outside it, and cuts out holes (enclaves) as well. `auto-fit` frames the layer extent once the metadata is loaded; `fit()` is also available on the component instance:

```vue
<script setup lang="ts">
import type { Polygon } from 'geojson'

const district: Polygon = { type: 'Polygon', coordinates: [[[121.5, 29.9], [121.7, 29.9], [121.7, 30.05], [121.5, 30.05], [121.5, 29.9]]] }
const imagery = useTemplateRef('imagery')
</script>

<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 11 }">
    <MaplibreZztsLayer ref="imagery" :url="mediaUrl" :clip="district" :fit-options="{ padding: 40 }" />
  </MaplibreMap>
  <UButton label="Fit" @click="imagery?.fit()" />
</template>
```

### 3D scenes

Because requests are clipped to the layer extent, every zoom level renders: the imagery stays visible when zooming out to the globe and in the distance at high pitch, and MapLibre drapes it over terrain natively. On HiDPI screens set `pixel-ratio` to request one finer grid level:

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12, pitch: 70, maxPitch: 85 }">
    <MaplibreProjection type="globe" />
    <MaplibreTerrain :source="demSource" :exaggeration="1.5" />
    <MaplibreZztsLayer :url="mediaUrl" :pixel-ratio="2" />
  </MaplibreMap>
</template>
```

## Register the protocol

`MaplibreZztsLayer` registers the protocol with default options. Register it up front when using `MaplibreRasterLayer` directly:

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { zzts: true }
  }
})
```

```ts [main.ts (Vue + Vite)]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

registerZztsProtocol()
```
::

### Custom requests

When the endpoints need auth headers or a proxy, register the protocol yourself in a client plugin with a custom `fetch`; metadata, element lists and element images all go through it. For services that need different settings, register each under its own `scheme` and pass that `scheme` to the component:

```ts [plugins/zzts.client.ts]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

export default defineNuxtPlugin(() => {
  registerZztsProtocol({
    scheme: 'zzts-auth',
    fetch: (input, init) => fetch(input, { ...init, headers: { sessionId: useCookie('sessionId').value ?? '' } })
  })
})
```

| Option | Description |
|--------|-------------|
| `scheme` | Protocol name, defaults to `'zzts'`; registering the same name again ignores the new options with a warning |
| `fetch` | Custom request function, defaults to the global `fetch` |
| `cacheSize` | Number of cached element images (compressed data), defaults to `256` |
| `retry` | Retries on network errors or 5xx, defaults to `2`; 404 is not retried |
| `metatileSize` | Edge length of a merged request in tiles (a power of two), defaults to `2`; set `1` to disable merging |
