## Introduction

A ZZTS dynamic tiling service serves imagery on a GeoSOT grid: the `media` endpoint returns the layer extent, and the `media/elements` endpoint returns the grid images (with WGS84 extents) visible in a viewport. The `zzts://` protocol composes and reprojects those grid images into 512px Web Mercator tiles in the browser, so rendering stays on the native MapLibre raster pipeline: tile caching, parent-tile fallback with fading, and aborting requests for tiles leaving the viewport all work out of the box.

After registering it, set the `url` of `MaplibreRasterLayer` to `zzts://` followed by the `media` endpoint address (including query parameters such as `layerName` and `dictCode`).

::note
Set `tileSize` to `512` to match the protocol output and scale calculation. `minzoom` / `maxzoom` are derived from the layer metadata by default and can be overridden on `MaplibreRasterLayer`.
::

## Register the protocol

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { zzts: true }
  }
})
```

```ts [main.ts (Vue + Vite)]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

registerZztsProtocol()
```
::

## Usage

```vue
<template>
  <MaplibreMap :options="{ center: [121.6, 29.98], zoom: 12 }">
    <MaplibreRasterLayer
      url="zzts://https://example.com/sstde_v4/v1/zzts/layer/media?layerName=xxx-01&dictCode=xxx"
      :tile-size="512"
      :opacity="0.8"
    />
  </MaplibreMap>
</template>
```

::tip
Query parameters on the address are forwarded to both the `media` and `elements` endpoints, so service parameters such as `layerId` or `token` can simply be appended.
::

::note
Grid images that fail to load (for example a 404 because the service has not generated them yet) are filled from up to 3 coarser levels drawn underneath; 404 results are cached and not requested again.
::

## Custom requests

When the endpoints need auth headers or a proxy, leave the module option off and register the protocol yourself in a client plugin with a custom `fetch`; metadata, element lists and element images all go through it:

```ts [plugins/zzts.client.ts]
import { registerZztsProtocol } from '@movk/maplibre/utils/zzts'

export default defineNuxtPlugin(() => {
  registerZztsProtocol({
    fetch: (input, init) => fetch(input, { ...init, headers: { sessionId: useCookie('sessionId').value ?? '' } }),
    cacheSize: 512
  })
})
```

| Option | Description |
|--------|-------------|
| `fetch` | Custom request function, defaults to the global `fetch` |
| `cacheSize` | Number of cached element images, defaults to `256`; neighbouring tiles sharing a grid image do not download it again |
