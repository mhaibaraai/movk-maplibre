## Introduction

[PMTiles](https://docs.protomaps.com/pmtiles/) packs a whole tileset into one file that the browser reads on demand with HTTP range requests, so no tile server is needed. Once the `pmtiles://` protocol is registered, write a `pmtiles://` address as the `url` of `MaplibreSource` or `MaplibreRasterLayer`.

::note
Requires the optional dependency `pmtiles`, and the file host must support range requests and CORS.
::

## Register the protocol

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/maplibre'],
  maplibre: {
    protocols: { pmtiles: true }
  }
})
```

```ts [main.ts (Vue + Vite)]
import { registerPmtilesProtocol } from '@movk/maplibre/utils/pmtiles'

// Register synchronously before the first map is created; repeated calls register once
registerPmtilesProtocol()
```
::

`registerPmtilesProtocol` returns the `Protocol` instance, so you can register custom sources (such as local files) with `protocol.add(new PMTiles(source))`.
