## Introduction

`MaplibrePopup` anchors a popup at the specified `lnglat`, rendering arbitrary content via the default slot. The position updates reactively when `lnglat` changes, and a `close` event is emitted when the popup is dismissed.

::note
`MaplibreTooltip` holds a single Popup instance and cannot show several feature popups at once — its `feature` comes from mouse events, and the component does not hold the feature list. To keep layer-feature popups open simultaneously, iterate the source array that builds your GeoJSON and render one `MaplibrePopup` per point. If your points are DOM markers, [`MaplibreMarker`](/docs/core/marker) with `:open="true"` is more direct.
::

### Long Content and Default Styles

Popups share the `movk-popup` class, with rounded corners, a border, shadow, text wrapping, and thin scrollbars. The native MapLibre close button retains its behavior, with a 28px hit area, a 20px close symbol, and hover, pressed, and keyboard-focus states. Popups without a close button do not reserve that space. These styles also apply to the Marker `#popup` slot and `MaplibreTooltip`, without a Nuxt UI dependency.

Scrollbar styling only affects existing scrollable content and does not impose a height limit. Set `max-height` and `overflow-y: auto` inside the slot for long lists. This example also exposes a long title, the close button, light/dark appearance, and arrow directions:

### Custom Appearance

`options.className` is preserved alongside `movk-popup`. Override the following CSS variables in global styles using your custom class. Defaults use the host's Nuxt UI theme variables when available, with standalone light and `.dark` fallbacks otherwise.

| CSS Variable | Purpose |
| --- | --- |
| `--movk-popup-bg` | Content and arrow background |
| `--movk-popup-color` | Body text color |
| `--movk-popup-muted` | Close button color |
| `--movk-popup-border` | Border color |
| `--movk-popup-radius` | Content corner radius |
| `--movk-popup-shadow` | Popup shadow |
| `--movk-popup-focus` | Close button focus color |
| `--movk-popup-scrollbar` | Scrollbar thumb color |
| `--movk-popup-scrollbar-hover` | Hovered scrollbar color |
| `--movk-popup-font-family` | Popup font family |

```vue
<MaplibrePopup :lnglat="[116.397, 39.908]" :options="{ className: 'site-popup' }">
  Custom popup content
</MaplibrePopup>
```

```css
.site-popup {
  --movk-popup-radius: 12px;
  --movk-popup-focus: #2563eb;
}
```

::note
Popup content is mounted inside the map DOM. Set inherited variables on the map container, its ancestors, or a global custom class; variables defined only on the slot's original Vue ancestors may not reach the popup. With scoped component styles, use a global selector or pass variables through the map container.
::
