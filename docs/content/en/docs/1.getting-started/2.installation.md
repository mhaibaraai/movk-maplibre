## Requirements

::callout{color="info"}
- **MapLibre GL JS** — v6 (`maplibre-gl` as a peer dependency)
- **Vue** — 3.4+
- **Node.js** — `^20.19.0 || >=22.12.0`
- MapLibre itself **needs no access token**; if you need Tianditu basemaps, you'll also need a Tianditu `tk`
::

## Install Dependencies

::code-group
```bash [pnpm]
pnpm add @movk/maplibre maplibre-gl
```

```bash [npm]
npm install @movk/maplibre maplibre-gl
```

```bash [yarn]
yarn add @movk/maplibre maplibre-gl
```
::

For drawing support (`MaplibreDrawControl`), also install:

::code-group
```bash [pnpm]
pnpm add terra-draw terra-draw-maplibre-gl-adapter
```

```bash [npm]
npm install terra-draw terra-draw-maplibre-gl-adapter
```

```bash [yarn]
yarn add terra-draw terra-draw-maplibre-gl-adapter
```
::

Install the other optional dependencies only when needed; the rest of the library works without them:

| Dependency | Purpose |
| --- | --- |
| `pmtiles` | [PMTiles](/docs/extensions/pmtiles) single-file tile protocol |
| `@geomatico/maplibre-cog-protocol` | [COG](/docs/extensions/cog) Cloud Optimized GeoTIFF protocol |
| `maplibre-contour` | [MaplibreContourLayer](/docs/layers/contour) on-the-fly contours |
| `lottie-web` | [MaplibreLottieMarker](/docs/core/lottie-marker) animated markers |

## Choose a Setup Method

::card-group
  :::card{icon="i-simple-icons-nuxt" title="Nuxt 4" to="/docs/getting-started/nuxt"}
  Register as a Nuxt module — components and composables are auto-imported.
  :::

  :::card{icon="i-logos-vue" title="Vue + Vite" to="/docs/getting-started/vue"}
  Use the Vite plugin + vue-plugin to use the same components in a plain Vue project.
  :::
::
